# 碧桂园服务品牌资产自检

本文件用于创建或检查碧桂园服务 PPT HTML deck 的品牌资产。目标不是做泛品牌研究，而是确保每次交付都能稳定识别为碧桂园服务风格。

## 必须资产

默认资产来自本 skill：

- 主 logo：`assets/ppt-base-template/模版底图/image1.png`
- 浅色水印：`assets/ppt-base-template/模版底图/image5.png`
- 基础模板：`assets/ppt-base-template/PPT基础模版.html`

生成用户项目时，应复制到项目的 `shared/模版底图/`：

- `shared/模版底图/image1.png`
- `shared/模版底图/image5.png`

除非用户提供新的官方模板或明确要求去除，不要替换、重画、拉伸或纯文字代替 logo。

## 项目素材自检

如果页面涉及具体项目、现场、设备、维保、工程、客户活动或数据截图，优先使用真实素材。

| 素材类型 | 最低要求 | 不足时处理 |
|---|---|---|
| 项目/现场照片 | 来源明确、清晰、不泄露敏感信息 | 用标注清楚的占位图，不编造现场 |
| 设备/工程照片 | 能说明问题或成果，不只是装饰 | 向用户索取，或改用表格/流程表达 |
| 数据截图 | 可读、来源明确、已脱敏 | 转成表格或图表，不放模糊截图 |
| 外部品牌/合作方 logo | 使用官方文件或用户提供文件 | 找不到就标注待补，不手画 |
| 地图/区位图 | 来源合规，必要时简化为示意图 | 不使用不明来源截图 |

## 品牌 token 自检

每个项目建议在 `shared/tokens.css` 固化以下变量：

```css
:root {
  --bgy-blue: #006d9a;
  --bgy-deep-blue: #004b6b;
  --bgy-red: #c00000;
  --bgy-green: #2e7d32;
  --text-main: #1f2933;
  --text-muted: #64748b;
  --panel: #f5f8fa;
  --line: #d8e3ea;
}
```

使用规则：

- 标题、章节号、关键线条优先用 `--bgy-blue`。
- 风险、逾期、负偏差只用红色，不用大面积红底。
- 完成、改善、正向结果用绿色。
- 灰色只做辅助，不承载关键指标。
- 单页除灰阶外，不超过 3 种强调色。

## 禁止事项

禁止：

- 用 CSS 或 SVG 重画碧桂园服务 logo。
- 只用文字“碧桂园服务”替代官方 logo。
- 拉伸、压扁、裁切 logo。
- 把 logo 放在低对比度背景上。
- 随意改品牌蓝为其他蓝色。
- 用通用地产、物业、科技插画冒充真实项目素材。
- 编造指标截图、客户评价、项目照片或现场图片。

## 交付前品牌检查

交付前逐项确认：

- [ ] `index.html` 和每页 `slides/*.html` 中 logo 路径有效。
- [ ] 默认模板页保留右上角 logo 和右下角水印。
- [ ] 所有项目照片、数据截图、外部 logo 均来源明确或标注待补。
- [ ] `shared/tokens.css` 中品牌色统一，没有临时发明近似色。
- [ ] 页面看起来是碧桂园服务管理汇报，而不是通用网页、科技发布会或营销海报。
