# 碧桂园服务 PPT HTML 交付前评审清单

本清单用于最终交付前自检。重点看问题和风险，不做泛泛审美评价。

## 评分维度

建议按 5 个维度各给 1-10 分，低于 7 分的维度必须修：

| 维度 | 检查重点 |
|---|---|
| 品牌一致性 | 是否保留碧桂园服务 logo、水印、品牌蓝、企业汇报气质 |
| 视觉层级 | 观众是否一眼知道先看标题、再看指标、最后看说明 |
| 内容功能性 | 每页是否只有一个核心观点，数据是否有解释 |
| 细节执行 | 对齐、间距、表格、字号、色彩是否统一 |
| 交付可用性 | HTML/PDF 是否能打开，图片是否丢失，页面是否无溢出 |

## 必查项

内容：

- [ ] 每页标题是结论句，不是泛泛栏目名。
- [ ] 每页只讲一个核心信息。
- [ ] 数据有业务解释，不是只放数字。
- [ ] 风险、待协调、逾期事项有责任或下一步动作。
- [ ] 没有 `TODO`、`placeholder`、假数据、未说明占位图。

视觉：

- [ ] 页面保持 16:9。
- [ ] 正文位于标题栏下方，未遮挡 logo 或水印。
- [ ] 关键文字投影尺寸可读。
- [ ] 表格不挤，列数和行数可读。
- [ ] 同类组件对齐一致，间距一致。
- [ ] 单页颜色不过多，红色只用于风险或负向信息。

品牌：

- [ ] 右上角 logo 清晰且不变形。
- [ ] 右下角水印不干扰正文阅读。
- [ ] 品牌蓝使用一致。
- [ ] 整体气质克制、专业、适合内部管理汇报。

技术：

- [ ] `index.html` 能打开。
- [ ] `window.DECK_MANIFEST` 中每个 `file` 路径有效。
- [ ] 每页 `slides/*.html` 可单独打开。
- [ ] 本地图片路径有效，无破图。
- [ ] 可运行时，已用 `scripts/verify.py` 截图检查。
- [ ] 需要 PDF 时，已用 `scripts/export_deck_pdf.mjs` 导出并确认文件大小正常。

## 常见问题与修复

| 问题 | 修复 |
|---|---|
| 标题像栏目名 | 改成结论句，例如 `5月消防维保完成率保持100%` |
| 页面太满 | 拆页，或保留一个主表/主图，删弱信息 |
| 表格难读 | 减列、合并弱字段、提高行高、突出状态列 |
| 红色过多 | 只保留真正风险项，其余用灰阶或品牌蓝 |
| 指标没有意义 | 增加同比/环比/目标值/完成率之一 |
| 水印遮字 | 移动正文区域或降低正文块透明度依赖 |
| 图片像装饰 | 替换为能证明问题/成果的真实图，或删除 |

## 评审输出格式

如果需要向用户报告评审结果，使用：

```markdown
总体判断：可交付 / 需小修 / 需重做

主要问题：
1. [严重程度] 问题说明 - 修复方式
2. [严重程度] 问题说明 - 修复方式

已通过：
- 品牌一致性
- 页面比例与路径
- 内容结构

验证：
- 已运行/未运行 verify.py
- 已导出/未导出 PDF
```
